## Download

Download the latest release from the [Releases](https://github.com/Seijii-Dev/knox/releases/latest) page.

## Building

```bash
git clone --recurse-submodules https://github.com/Seijii-Dev/knox.git
cd knox
./gradlew prepareTreeSitter
./gradlew assembleDebug
```

## Requirements

* Android 9.0 (API 28) or later
* Android Studio Quail or newer
* Android SDK and NDK

## Status

Knox is under active development. Features and APIs may change between releases.
